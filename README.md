
# Android App Scheduler

Android App Scheduler is a Kotlin-based Android application that helps users efficiently schedule and manage opening of any installed app.

## Features

- scheduled opening of an app.
- Show all the schedules for every installed applications.
- Delete a scheduled opening.
- Modify schedule of opening.

## Getting Started

### Prerequisites

- Android Studio (latest version recommended)
- Android device or emulator with API level 24 or higher

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MahmudMoon/AndroidAppScheduler.git
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Build and run the app on an emulator or physical device.

## Usage

1. Launch the app on your Android device.
2. Provide the necessary permissions.
3. Add Schedules by clicking on the app name from the list.
4. Select the time for the schedule.
5. Click the right arrow and open the detail screen.
6. Delete a schedule by clicking on the delete icon.
7. Modify a schedule by clicking on the edit icon.
